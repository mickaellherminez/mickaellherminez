## 🤝 Open source & community

### 365 Day & Night — accessible VS Code themes · [repository](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext) · [website](https://365daynight.mickaellherminez.net)

- 48 themes: the 12 months in Light, Dark, High Contrast and High Contrast Light, with automatic day/night switching
- Automated audit of 13,212 checks (WCAG contrast, color vision deficiency simulations) enforced in CI: any regression blocks the release ([audit report](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext/blob/main/docs/AUDIT.md))
- Published on the VS Marketplace and Open VSX, 1,000+ installs (November 2026), website and README in 10 languages, including Arabic
- **Stack**: JavaScript (VS Code extension API), Python, GitHub Actions

### Contribution to microsoft/vscode-docs

- [PR #10635](https://github.com/microsoft/vscode-docs/pull/10635), merged in November 2026: added the extension to the "Recommended themes for color vision accessibility" section of the VS Code documentation

### Community

- Mentoring: standards, onboarding, code reviews, upskilling
